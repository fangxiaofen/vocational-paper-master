# 审稿人视角质检清单与投稿适配模板

> 用途：第五阶段逐项质检，以及生成"投稿适配说明"。配合 `scripts/paper_selfcheck.py` 自动化初筛后人工复核。

## 一、学术质量质检（六维）

逐条以"达标 / 不足 / 缺失"判定，不足的给出修改点。

- **选题价值**：是否回应真问题？政策契合度、理论新意、实践意义是否具备？
- **理论支撑**：有无清晰学理分析框架？概念是否操作化定义？是否仅经验罗列？
- **方法适切**：研究方法是否匹配研究问题？抽样/资料来源是否交代清楚？
- **证据充分**：数据/案例/政策是否真实可溯？"已查证"与"一方称"是否区分？
- **结论稳妥**：结论是否回应研究问题？建议是否可操作、不过度外推？
- **文献规范**：引文是否真实、权威、体例统一（建议 GB/T 7714）？有无关键文献遗漏？

## 二、结构完整性核对

- [ ] 标题准确凝练、凸显创新点
- [ ] 摘要含目的—方法—结果—结论四要素，独立可读
- [ ] 关键词 3—6 个，覆盖领域/对象/方法
- [ ] 引言含问题提出、文献缺口、本文边际贡献
- [ ] 文献综述/现状分析有地图感（共识/空白/争议）
- [ ] 研究方法/设计可复现
- [ ] 核心分析层层递进，小标题有信息量
- [ ] 结论与建议回应研究问题
- [ ] 参考文献体例统一、近期文献占比合理

## 三、AI腔与查重风险排查

高频AI套话（出现即记录并改写）：总而言之、综上所述、值得注意的是、毋庸置疑、在当今社会、随着……的发展、近年来、日益、赋能、抓手、痛点和难点、一方面……另一方面、首先……其次……最后（机械排比）。

同质化句式：三段式"背景+意义+本文结构"开场；每段以"因此""所以"收尾；无具体数据却大量定性判断。

改写原则：用具体主语与动作替代抽象连接词；以证据句起段；保留用户原意，压缩空泛过渡。

## 四、投稿适配说明模板

生成成稿时一并输出：

```
【目标期刊】首选：___ ；备选：___
【匹配栏目】___（待官网核实）
【题目备选】
  1. ___
  2. ___
  3. ___
【创新点提炼】理论/方法/对象/数据：___
【审稿人重点关注】___
【查重与合规提醒】建议自查重复率（目标刊阈值待核实）；确保无AI代写痕迹、无一稿多投
【待核实事项】___（政策文号、栏目名称、查重阈值等需用户确认项）
```

## 五、质量红线复核

- [ ] 无编造数据/文献/政策/案例/访谈对象
- [ ] 无空洞概念替代实质分析
- [ ] 非政策宣讲稿/经验总结/口号式文本
- [ ] 引文、术语、图表格式统一规范
- [ ] 用户指定方向已采纳，冲突处已提示风险
